Cartographic Map Catalogue

A collection of cartographic work exploring the intersection of geography, design, and visual communication. These maps emphasize thoughtful composition, symbology, typography, and visual hierarchy to communicate geographic information clearly and effectively.

01 / 06

US Feature Labeling

The map was created by labeling a collection of US features to a USGS physical raster map of the United States. From a cartographic perspective, labels were strategically placed to clearly identify important physical features while maintaining readability and visual balance. Point, line, and area features were labeled according to appropriate typography and placement principles, with attention given to avoiding overlap and maintaining a clear visual hierarchy.

ArcGIS Pro · Adobe Illustrator · 2025

02 / 06

Delta Flights Animated Flow Map

The maps visualize Delta flights departing from Detroit Metropolitan International Airport on June 21, 2022, between 7:00 and 8:30 AM. The flow map connects the departure airport to each destination using lines, with line size representing the passenger capacity of each aircraft. The temporal visualization incorporates flight times and uses animation to show flight patterns. This map illustrates my ability to work with time fields in ArcGIS Pro, and use the animation tools to create a temporal visualization.

ArcGIS Pro · Animation · 2025

Delta Flights Flow Map

04 / 06

Maui Terrain and 3D Image Map

This map is a 3D visualization of Maui's terrain, hotels, and roads using elevation and shape file data. I used Google Earth Engine to download a Digital Elevation Model (DEM) and then brought the data into ArcGIS Pro to create a 3D scene. The main goal was to learn the cartographic workflow from collecting elevation data to transforming it into a visually appealing terrain visualization. With this map, I gained experience working with DEM data, creating and navigating 3D scenes in ArcGIS Pro, and using different visualization techniques to represent terrain and elevation in three dimensions.

ArcGIS Pro · 3D · ArcGIS Pro Styles · 2026

05 / 06

LotR Style Arizona Map

This map illustrates a Lord of the Rings-inspired depiction of Arizona’s natural features and landmarks. I created a custom basemap using Esri’s Vector Tile Style Editor and incorporated an available Lord of the Rings-style package from the ArcGIS Pro Styles website to give the map a unique visual design. Through this lab, I learned how to customize the appearance and symbology of basemap layers, work with vector tile styles, and import and apply existing style packages in ArcGIS Pro. I developed my skills in visual hierarchy, color and symbol selection, and designing a map that communicates geographic information while maintaining a consistent theme and aesthetic.

ArcGIS Pro · Esri Vector Tile Style Editor · ArcGIS Pro Styles · 2026

06 / 06

Bivariate Virginia Home Ownership and Population Map

This map visualizes multiple variables across Virginia counties by combining a choropleth map with a 3D local scene. The home ownsership variable was represented using color, while population was used to control the height of each county, allowing two dimensions of data to be displayed simultaneously. Using ArcGIS Pro, I learned how to create and symbolize choropleth maps, convert a 2D map into a local 3D scene, and use attribute data to control the elevation of geographic features. I developed skills in navigating and adjusting the viewing perspective of a 3D map, helping me understand how three-dimensional visualization can reveal patterns and relationships that may be harder to see on a traditional 2D map.

ArcGIS Pro · 3D · Bivariate · 2026
